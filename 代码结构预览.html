任务管理 / harness_core

决定固定工具能否运行，管理任务状态，并保存结果与审计记录。

在下方查看对应文件 ↓
python -m harness_core --data-dir local-data/new-harness

命令示例在 qupath-agent/ 下运行；网页不会执行它。

输入
已注册工具、只读 Profile、任务与会话标识。
输出
REPORT_READY / FAILED、SQLite 任务记录和摘要产物。
入口
qupath-agent/harness_core/runtime.py

当前只挂载一个受信任的固定统计工具；不调用模型，不执行任意候选代码。

沿一条路线，看代码怎样走

源码调用关系示意，切换不会执行任务

  1. 声明能用什么

    入口挂载固定统计工具，限定只读 Profile，并创建运行时。

    harness_core/__main__.py

  2. 检查权限与任务

    检查工具、输入和幂等标识，按状态机推进任务。

    Runtime.run()

  3. 复用固定统计

    run_case 读取冻结用例，计算已有类别的统计，并做 L2 一致性检查。

    run_case() → execute_mps()

  4. 保存产物与审计

    验证输出结构，保存摘要产物，落盘任务与审计事件。

    Store.put() / Store.save()
CREATED → TASK_VALIDATING → EXECUTING → L2_VERIFYING → REPORT_READY；异常路径可进入 FAILED。

这条路线运行的是已注册的固定统计程序，输入为已有类别名单；不包含 AI 生成代码或真实图像细胞识别。

  1. 接收任务与代码文本

    读取明确的合成像素、任务规格及人工或外部候选文本。

    agent_lab/__main__.py

  2. 记录版本与反馈

    用摘要绑定输入、候选、父版本与反馈，保存完整记录。

    new_candidate() / save_bundle()

  3. 检查结构与一致性

    检查允许的 AST 形状及文件完整性；固定参考独立计算。

    preflight() / check_bundle()

  4. 可整理首次模型输入

    单独调用 prepare_coder，投影任务、像素与接口，输出 PREPARED。

    prepare_coder()

当前终点：NOT_EXECUTED。结构检查通过、固定参考值和 PREPARED 都不能算候选执行结果或模型调用证据。

  1. 采集本机环境

    记录 Python、依赖与外部命令的可用情况。

    check_environment.py

  2. 探查 QuPath 侧 API

    Groovy 与 Java 扩展探针检查对象、图像与接口信息。

    qupath_probe.groovy

  3. 独立检查指纹与隔离

    提供 Java 指纹对照与 Docker 限制检查代码；按具体环境单独运行。

    isolation_probe.py

  4. 产品连接仍待完成

    后续才是 Java ↔ Python 服务、QuPath 内展示结果及批准后写回。

    尚无已接通的产品链路

这些是独立探针的阅读顺序，不是自动执行流水线。存在探针文件不能代替实机权限、隔离与 QuPath 集成验收。

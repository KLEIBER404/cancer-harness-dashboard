    Runtime.run()

  3. 复用固定统计

    run_case 读取冻结用例，计算已有类别的统计，并做 L2 一致性检查。

    run_case() → execute_mps()

  4. 保存产物与审计

    Store.put() / Store.save()
CREATED → TASK_VALIDATING → EXECUTING → L2_VERIFYING → REPORT_READY；异常路径可进入 FAILED。

这条路线运行的是已注册的固定统计程序，输入为已有类别名单；不包含 AI 生成代码或真实图像细胞识别。

    new_candidate() / save_bundle()

    preflight() / check_bundle()

    prepare_coder()

当前终点：NOT_EXECUTED。结构检查通过、固定参考值和 PREPARED 都不能算候选执行结果或模型调用证据。
